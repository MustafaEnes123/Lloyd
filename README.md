## Overview

Lloyd is an autonomous, fully offline digital desktop companion engineered specifically for Apple Silicon (M1/M2/M3/M4). Built entirely by **Mustafa Enes Kayaci (Enes)**, Lloyd runs fully within your local environment with zero telemetry or cloud reliance.

### Key Capabilities
- **Neural Expressive UI**: Aesthetic glassmorphism, glowing telemetry, and dynamic ambient lighting.
- **Real-Time 3D Anime Avatar**: Cel-shaded interactive character featuring procedural head tracking, eye-blinking, and voice-synced mouth movements.
- **Local Speech-to-Text**: Low-latency transcription powered by whisper.cpp (tiny.en) on Apple Silicon.
- **Local Neural Intelligence**: Driven by an Apple Silicon Metal-accelerated inference engine.
- **Natural Voice Synthesis**: Offline neural text-to-speech utilizing Piper ONNX.
- **Zero-Fuss Onboarding**: Automated background weight downloader and SHA-256 asset verification wizard.

## Installation

1. Download the latest installer: [**Lloyd-macOS-arm64.dmg**](https://github.com/MustafaEnes123/Lloyd/releases/latest/download/Lloyd-macOS-arm64.dmg)
2. Open the `.dmg` file and drag **Lloyd** into your **Applications** folder.
3. Launch the application. On first startup, the Onboarding Wizard will automatically download and verify required local neural models into `~/Library/Application Support/Lloyd/models`.
4. Grant microphone permissions when prompted to enable voice interactions.

## Customization & Controls
